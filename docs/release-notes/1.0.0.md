PenPilot 1.0, the first full release.

- Turn drawings, photos and text (handwriting and Arabic fonts too) into pen lines and plot them on an AxiDraw
- Fill shapes and letters with hatching; add rectangles, circles and borders
- Several pens on one page: PenPilot stops and asks for the next pen
- Tick which drawings to plot, and continue from any line after a stop
- Undo, redo, zoom, and save your page as a project
- From now on, new versions arrive by themselves: PenPilot tells you when one is ready
