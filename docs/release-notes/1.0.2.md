PenPilot 1.0.2: updates now work on Windows.

- Windows: Update now installs the new version and opens PenPilot again by itself (before, PenPilot closed and the update never ran)
- Windows: if PenPilot is on 1.0.0 or 1.0.1, install 1.0.2 once by hand; later updates then arrive by themselves
- Windows: if an update can't start, PenPilot stays open and says so instead of closing
- Windows: thinner scrollbars in PenPilot's colours
- Plotter check's technical details say which ports PenPilot left alone (it only ever uses the AxiDraw)
