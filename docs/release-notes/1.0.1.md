PenPilot 1.0.1: fixes from a full check of the app.

- If the plotter is unplugged or switched off during a plot, PenPilot now stops cleanly and offers "Continue from line" (it used to wait forever)
- Motors off, the paper and the Advanced settings are locked while a plot is running or paused, so the rest of a drawing can't land in the wrong place
- Pasting text into a text box no longer shows "couldn't read the pasted text"; pasting an SVG onto the page still adds it as a drawing
- Project files are checked when opened, so a damaged file can't freeze PenPilot
- Extra security: PenPilot refuses permissions it doesn't need, only its own screens can use its desktop features, and the app can't be started in other ways
- If you keep PenPilot open while an update is waiting, it now says the update finishes when you close it
