# Final polish test (build step 7), Mac

About 10 minutes. Install PenPilot 1.0.0 first (quit the old one, drag the new one into
Applications, and choose **Replace**). The first time, right-click it → **Open**, as before.

1. **Icon:** the Dock and Applications show the new icon (the pen carriage on purple). If
   Finder still shows the old one, it catches up after a minute or a restart.
2. **Welcome guide:** it opens by itself the first time. Read through it with **Next**, then
   **Start**. It doesn't come back by itself. **Help** (under the PenPilot name) opens it again.
3. **Double-click a project:** quit PenPilot, then double-click a saved `.penpilot` file
   (e.g. `Card.penpilot` from the last test) in Finder. PenPilot opens with that page.
   - If macOS asks which app to use, choose PenPilot once.
4. **While PenPilot is open,** move something on the page, then double-click another
   `.penpilot` file. PenPilot asks first (unsaved changes), then opens it in the same window.
5. **The tidier panel:**
   - **File** in the menu bar at the top of the screen has New, Open, Save, Save as and
     Export SVG (⌘S still saves). **Help** there has the welcome guide and the Plotter check.
   - **Pen**, **Paper**, **Drawings** and **Advanced** fold up: click a title to open or
     close it. Closed, each shows a one-line summary. Quit and reopen: they stay as you left
     them.
   - The plotter status at the top is a small button: click it for the Plotter check.
   - Pen: **Raise / Lower / Test square** in one row; **Edit pen settings** opens the heights,
     speed, width and colour. **+** adds a pen. **Motors off** is the small link under it.
   - Drawings: **+ Add** opens a menu (drawing or photo, text, rectangle, circle, border).
     Select a drawing: its **Pen**, **Fill** and **Size and position** fold up too.
   - **Reverse pen direction** has moved to **Advanced** (it should still be ticked).
   - Plot: **Frame** and **Plot** side by side; **Pause** and **Stop** appear only while it plots.
6. Plot anything small to check plotting still works as before.
