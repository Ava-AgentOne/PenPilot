# Single-line text test (build step 4)

About 10 minutes on the Mac. You need: the plotter, an A4 sheet (or a card), a fine pen.
Install PenPilot 0.4.0 first (quit the old one, drag the new one into Applications, and
choose **Replace**).

## 1. Write something

1. Press **Add text** (in the **drawings** section). "Hello" appears in the middle of the page.
2. In the text box, type a short message. **Enter** starts a new line, e.g.:

   ```
   Happy Birthday
   to you!
   ```

3. Try a few **fonts**. Every one draws each letter as a **single pen stroke**, like
   handwriting: no hollow letters. Good ones to start with: **EMS Readability** (clean),
   **EMS Allure** and **Hershey Script** (handwriting), **Hershey Gothic English** (old style).
4. Set **letter size** (the height of capital letters, in mm), **Letter spacing**,
   **Line spacing**, and **Left / Centre / Right**.
5. Move and resize it like any drawing. Dragging the corner changes the letter size too.

These fonts cover English letters, numbers and punctuation. If you type a letter a font
doesn't have (e.g. Arabic), PenPilot says which ones it can't write.

## 2. Plot it

1. Put text and a drawing on the same page if you like (e.g. the traced hand plus a caption).
2. **Frame** to check the position, then **Plot**.

## Report back

- Do the letters come out as single clean strokes, and is the size right? (Measure a
  capital letter: it should match the size you typed.)
- Which fonts do you like or not like?
- Anything you'd want for text that's missing (e.g. curved text, more fonts, Arabic)?
